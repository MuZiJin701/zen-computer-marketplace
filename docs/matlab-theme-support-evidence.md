# Windows MATLAB 桌面主题支持评估

2026-11-22 核查。**MATLAB 支持给内置浅色、深色主题自定义配色，值得列为候选，但现有证据不足以纳入 One-Tone 的自动支持范围。** 当前 Target 矩阵未列入 MATLAB，显式传入 `matlab` 走未知 Target 的 `skipped` 路径。只读检查通过 `HKLM` 下的 MathWorks `MATLABROOT`、实际 `matlab.exe` 和 `VersionInfo.xml` 确认当前机器安装了 R2026a（26.1），并发现对应的 Roaming 设置目录。PATH 和默认 Program Files 路径未定位到该安装。本次未启动 MATLAB，也未修改配置或验收实际渲染。 [Target 矩阵](../plugin/skills/zen-one-tone-windows/references/targets.md) · [CLI 注册逻辑](../plugin/skills/zen-one-tone-windows/src/one_tone/cli.py#L264) · [未知 Target 处理](../plugin/skills/zen-one-tone-windows/src/one_tone/adapters/base.py#L43)

## 自定义范围

- R2025a 起，Windows MATLAB 的 `MATLAB > Appearance > Desktop Theme` 提供 `Light`、`Dark` 和默认的 `System`。`System` 随操作系统深浅色变化。`Appearance > Colors` 分别保存两种主题的颜色覆盖，可改 Editor、Live Editor、Command Window、Files、Workspace 和 Import Tool 的正文与背景，以及语法高亮、错误、警告、链接和部分编程工具颜色。可确认的覆盖限于官方文档列出的设置。 [桌面主题与配色](https://www.mathworks.com/help/matlab/matlab_env/change-desktop-colors-and-select-dark-theme.html) · [MathWorks Support](https://www.mathworks.com/matlabcentral/answers/2180679-how-do-i-set-custom-themes-in-matlab-r2025a-and-later#answer_1571226)
- R2026a 及当前 R2026b 文档都将 `matlab.colors` 的颜色限于 Light，包括部分语法、输出和 Code Analyzer 颜色，RGB 分量范围为 `0–255`。`matlab.editor` 另有当前行和右边距指示线颜色。本次未找到公开的桌面主题注册接口、双 Mode 读写接口，或覆盖标题栏、工具条等窗口界面的 Seed Color 入口。仅写 Light 语法色也无法保证它在用户自定背景上的对比度。 [R2026a `matlab.colors`](https://www.mathworks.com/help/releases/R2026a/matlab/ref/matlab.colors-settings.html) · [R2026b `matlab.colors`](https://www.mathworks.com/help/matlab/ref/matlab.colors-settings.html) · [`matlab.editor`](https://www.mathworks.com/help/matlab/ref/matlab.editor-settings.html) · [Settings API 索引](https://www.mathworks.com/help/matlab/matlab-environment-control.html)
- MathWorks Desktop Team 的 MATLAB Color Theme Extensions 声明支持 R2025a 起的桌面版本。JSON 方案要求 `DesktopTheme` 指定 `Light` 或 `Dark`，导入可切换桌面主题后再覆盖颜色，导出只记录当前主题的自定义颜色。上游公开了模板和 `.p` 导入导出程序，公开材料未说明如何读取非活动 Mode、恢复原有 `System` 选择，或区分未设值与显式设置为默认值。JSON 方案可作为手动配色的候选产物，其导出能力不足以证明符合 One-Tone 的 Snapshot 契约。 [上游说明](https://github.com/mathworks/matlab-color-theme-extensions/blob/4788735e47f9d957a5482d723542bf49e577553c/README.md) · [固定版本模板](https://github.com/mathworks/matlab-color-theme-extensions/blob/4788735e47f9d957a5482d723542bf49e577553c/template.json) · [MathWorks Support](https://www.mathworks.com/matlabcentral/answers/2180679-how-do-i-set-custom-themes-in-matlab-r2025a-and-later#answer_1571226)

## 自动化与回滚边界

- **启动与持久化。** R2026a 和 R2026b 的 Windows CLI 文档明确说明 `-batch` 禁止更改设置。普通启动可能创建、迁移或写入设置目录，也会执行启动目录或搜索路径上的启动脚本。默认 Windows 路径为 `%APPDATA%\MathWorks\MATLAB\<release>`，实际目录以 MATLAB 的 `prefdir` 为准，可能有自定义或临时目录。直接启动应用来发现设置目录不能证明 Preview 或 Verify 只读。官方目录说明也未提供可供外部直接改写的主题文件格式。 [R2026a Windows CLI](https://www.mathworks.com/help/releases/R2026a/matlab/ref/matlabwindows.html) · [当前 Windows CLI](https://www.mathworks.com/help/matlab/ref/matlabwindows.html) · [启动脚本](https://www.mathworks.com/help/matlab/matlab_env/startup-options.html) · [设置目录](https://www.mathworks.com/help/matlab/matlab_env/where-matlab-stores-settings.html) · [目录覆盖](https://www.mathworks.com/matlabcentral/answers/93696-how-do-i-change-the-matlab-preferences-directory-location)
- **设置文件线索。** 社区 R2025a 脚本尝试通过未公开的 `DesktopColors` 和 `SyntaxHighlightingColors` 设置配色，备用方案依赖 `matlab.mlsettings` 内的 `colors/settings.json`。本机 R2026a 的该文件为 ZIP，但当前存档中无脚本预期的条目。此观察仅适用于本机当前配置，尚无证据支持将该布局作为版本契约。 [社区脚本](https://github.com/dcacer/matlab-theme-switcher/blob/a4fbc083079882920feec8f95704c88df41cbdae/colorThemeSwitcher.m)
- **字段级快照。** 对有公开读写接口的字段，`PersonalValue` 持久化，`TemporaryValue` 只存在于当前会话且优先于 `PersonalValue`。Snapshot 应按字段记录 `hasPersonalValue` 及原值，Rollback 在原值存在时写回，原先缺失时用 `clearPersonalValue` 清除本次写入的覆盖。仅比较 `ActiveValue` 无法验证持久化，也无法精确还原。GUI 修改还会清除对应的 `TemporaryValue`，需要纳入任何自动导入路径的实测。 [Settings 取值规则](https://www.mathworks.com/help/matlab/matlab_external/access-and-modify-settings.html) · [`hasPersonalValue`](https://www.mathworks.com/help/matlab/ref/matlab.settings.setting.haspersonalvalue.html) · [`clearPersonalValue`](https://www.mathworks.com/help/matlab/ref/matlab.settings.setting.clearpersonalvalue.html)
- **图形副作用。** `theme(...)` 和 `Figure.Theme` 控制图窗。默认的 Figure Theme 跟随桌面主题，因此切换 Desktop Theme 可能改动现有图窗、绘图和 App 的默认配色，触发 `ThemeChangedFcn`。显式指定图窗主题可独立于桌面，显式指定的对象颜色也不会随主题重算。候选原型应保留 Desktop Theme 选择、Figure Theme 与绘图设置，并验证 Apply 未引起图窗换色。 [图形与 App 主题](https://www.mathworks.com/help/matlab/creating_plots/graphics-and-app-themes.html) · [`theme`](https://www.mathworks.com/help/matlab/ref/theme.html) · [`Figure` 回调](https://www.mathworks.com/help/matlab/ref/matlab.ui.figure.html)

## 重新评估条件

如需推进，先用独立的 Windows 测试用户验证明确选择的 R2026a 实例，仅覆盖有证据的桌面颜色。固定 Release、实际设置目录、字段及受管背景的证据，验证 Light/Dark 分别持久化且保留 `System`。在确认 Preview 和 Verify 无写入、部分失败可补偿、Rollback 可恢复原值和缺失状态之前，自动支持证据不足。配置匹配后另做实际界面的正文 `7:1`、功能文字 `4.5:1` 验收。 [One-Tone 架构](architecture.md) · [验证约定](testing.md) · [外观证据要求](adr/0010-evidence-backed-appearance-policy.md)
