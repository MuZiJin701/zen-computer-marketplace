## 安全策略与验证说明

- `Appearance policy 2026-11-25.v11`、双模式 Palette、冻结实例与字段能力共同纳入 Plan Hash；旧版 Plan 须经 Preview 重建，而历史事务 Rollback 保持独立。
- `chrome` 与 `matlab` 在写操作阶段采用 `Managed process shutdown`（先温和关闭 3 秒再强杀、写完不自动重开），并由入口与 `os.replace` 前二次 fail-closed `Live-process write guard` 复核退出。
- 实心窗口策略不把编辑器装饰叠层机械改为不透明；文字按真实合成背景验算。
- 真实 Windows 桌面渲染、TRAE/Antigravity IDE 私有 AI 面板、MATLAB 工具条 Chrome、Chrome 内部 Material 3 派生色阶、ChatGPT App 内嵌终端与真实 SSH 仍以 `rendering_verification = untested` 报告，需结合人工视觉验收（详见 [测试说明](testing.md)）。
